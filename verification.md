# Проверка готового проекта

Дата: 8 ноября 2026. Среда: Windows 11, Eclipse Temurin 21.0.13+9, Maven 3.9.11.

## Сборка

Выполнена общая Maven-сборка `spotless:apply verify`. Все модули завершились с `BUILD SUCCESS`; проверка Spotless пройдена. Сформированы четыре исполняемых Spring Boot JAR. Maven Wrapper также проверен на запуск Maven 3.9.11.

| Набор | Тестов | Ошибок / провалов |
|---|---:|---:|
| Общие JWT-компоненты | 4 | 0 / 0 |
| Eureka | 1 | 0 / 0 |
| Hotel Service | 13 | 0 / 0 |
| Booking: интеграционные сценарии | 15 | 0 / 0 |
| Booking: HTTP-клиент, тайм-ауты и circuit breaker | 4 | 0 / 0 |
| API Gateway | 37 | 0 / 0 |
| **Всего** | **74** | **0 / 0** |

Тесты запускают настоящую H2, проверяют права доступа, пересечения и смежные интервалы, повторную доставку, конфликт payload, гонки, компенсацию, восстановление и позднее подтверждение. HTTP-клиент проверяется в том числе реальным запросом с ограничением времени ожидания. Mockito подключён JVM как startup agent: тестам не требуется динамический attach.

## Совместный запуск

Через `scripts/start.ps1` запущены все четыре собранных JAR с настоящим Eureka service discovery. Затем `scripts/smoke.ps1` успешно выполнил **25 проверок**:

- Регистрация, вход администратора, выпуск JWT, анонимный доступ 401 и запрет административной операции пользователю 403.
- Создание отеля и номеров, рекомендации, автоматическое подтверждение и выбор по `timesBooked`, затем `id`.
- Повтор запроса возвращает тот же ID; изменённый payload с тем же ключом получает 409.
- Чужая бронь недоступна; история содержит только свои записи и поддерживает пагинацию.
- Пересечение дат получает 409; внутренняя операция release недоступна через Gateway даже ADMIN.
- Статистика считает занятые ночи, отмена идемпотентна и освобождает номер.
- **Восемь одновременных HTTP-запросов на один номер и период: одна подтверждённая бронь, семь конфликтов 409.**
- Следующее автоматическое бронирование выбирает менее использованный номер; отмена через REST-алиасы завершает компенсацию.

Оба `/v3/api-docs` ответили HTTP 200 и сформировали OpenAPI. После проверки все четыре процесса остановлены скриптом `stop.ps1`.

## Границы проверки

`docker compose config -q` завершился успешно. Контейнерная сборка и запуск Docker здесь не выполнялись; приложение проверено четырьмя отдельными JVM. Локальная проверка проведена на Java 21; Java 25 включена в матрицу GitHub Actions, но в этом отчёте её результат не заявляется.

H2 по ТЗ работает в памяти: потеря данных при перезапуске процесса ожидаема. Проверка восстановления компенсации относится к сохранённой записи внутри живого процесса, а не к аварийному восстановлению постоянной БД. Для повторной чистой демонстрации перезапускайте оба бизнес-сервиса вместе.

## Повторить

```powershell
.\mvnw.cmd verify
.\scripts\start.ps1
.\scripts\smoke.ps1
.\scripts\stop.ps1
```

Нужен JDK 21+ и свободные порты 8080, 8081, 8082, 8761. Отчёты JUnit после сборки находятся в `*/target/surefire-reports/`.
